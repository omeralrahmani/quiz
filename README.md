# ميدان الأسئلة — GitHub Pages

الموقع: https://omeralrahmani.github.io/quiz/

هذا المستودع يستضيف واجهة الموقع والصور والأفاتارات وقائمة المواضيع فعليًا، ولا يحوّل الزائر إلى Cloudflare.

الغرف واللعب المباشر تحتاج خادم Node.js وWebSocket منفصلًا. إذا لم يُحدد عنوان الخادم عند البناء، تعرض الواجهة حالة عدم الاتصال بوضوح وتسمح بتصفح المواضيع والشخصيات فقط. لم تُنشر الإجابات أو بيانات الغرف أو رموز الجلسات هنا.

إعادة البناء من المشروع المحلي: node --import tsx scripts/build-pages.ts
لربط الخادم بعد نشره، حدّد VITE_API_ORIGIN بعنوان HTTPS الخاص به عند البناء، ثم ارفع ناتج deploy/pages-site. يجب أن يسمح الخادم بطلبات CORS من https://omeralrahmani.github.io.

الخادم المتصل حاليًا: https://midan-quiz.onrender.com
خطة Render المجانية قد تستغرق نحو دقيقة عند الاستيقاظ بعد الخمول، والتخزين فيها مؤقت.
